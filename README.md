# dotnet-code-snippets

> *author*: [Mefamex](https://github.com/Mefamex) <br>

> *updates*: 2026-03-15 : .Net başlangıç ve paylaşım rehber seti oluşturuldu.

Bu repository, .NET projeleri icin pratik bir baslangic ve paylasim rehber setidir.

Amac:

- Projeyi hizli baslatmak
- Build/Run adimlarini standartlastirmak
- Makefile ile tekrar eden komutlari kisaltmak
- GitHub paylasim surecini netlestirmek

## Icindekiler

### [00 - Projeyi Olusturma](00_proje_olusturma/readme.md)
- Sifirdan .NET projesi olusturma
- Ilk calisma testi
- Onerilen solution yapisi

### [01 - Build Etme ve Calistirma](01_build_ve_calistirma/readme.md)
- `dotnet clean`, `dotnet build`, `dotnet run`
- `run.sh` ve `run.bat` kullanimi
- Release calisma secenegi

### [02 - Makefile](02_makefile/readme.md)
- `make build`, `make run`, `make rebuild`
- `CONFIG=Debug/Release` kullanimi
- `make getignore` ve `make nugetClean`

### [03 - GitHub'a Yukleme / Paylasma / Kullanma](03_github_paylasim/readme.md)
- `.gitignore` olusturma
- Ilk commit ve push
- Projeyi clone edip calistirma
